# CV Histogram Equalizer

Инструмент на Python для автоматического анализа экспозиции изображений. Скрипт вычисляет кумулятивную функцию распределения (CDF) и применяет алгоритм глобальной эквализации гистограммы (OpenCV) для нормализации контраста.

## Структура проекта
- `input_images/` — директория для исходных фотографий.
- `output_reports/` — автоматически генерируемые отчеты с графиками (Matplotlib).
- `main.py` — основной конвейер обработки.

## Запуск
1. Активируйте виртуальное окружение (`.venv`).
2. Установите зависимости: `pip install -r requirements.txt`
3. Выполните команду: `python main.py`
